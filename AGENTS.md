# Twin Wheels — Recomendações e Guias de Desenvolvimento

Projeto Twin Wheels — Gestão de Facção GTA RP.

- **Regra de Deploy:** Sempre que concluir totalmente as tarefas e modificações solicitadas, realizar o deploy da aplicação para a branch `gh-pages` com mensagem/título de deploy descritivo e coerente com a última modificação realizada (ex.: `npx gh-pages -d dist -m "mensagem descritiva"` ou `npm run deploy:spa`).
